# Gospel Game Show (Come Follow Me week 43, one-off)

## Why
Dillon's Sunday class (4-9 teens, 14-18) gets ~20 min after a 5 min video. He wants a calm, Quiplash-style game on the TV (laptop + HDMI) with phones as controllers, that gets teens thinking about real situations and the week's Jeremiah verses. Not rowdy, no multiple choice, always typed answers. Appears on students' Home screen for 2026-10-25 only.

## Goals / non-goals
- Goals: 8 typed-answer rounds, anonymous answers on the TV, vote, reveal names + one quiet verse; game-show announcer voice (pre-recorded clips); works for 3-10 players; host (teacher) controls pace.
- Non-goals: points, leaderboards, streak or pet rewards, DB changes, replays, moderation tooling beyond host removing an answer.
- Anti-goals: loud sounds, competitive pressure, preachy tone, names in prompts.

## How it works
- No database. A Supabase Realtime Broadcast channel `gameshow:<classId>` (verified working with the anon key). The teacher's laptop (`/teacher/gameshow`) is the single source of truth; phones (`/gameshow`) send hello / answer / vote and render the state the host broadcasts. Host state is mirrored to localStorage so a reload resumes.
- Phases per round: intro (announcer reads setup + ask) -> writing (100 s, auto-closes 2 s after everyone is in) -> voting (45 s, own answer excluded, auto-closes when all voted) -> reveal (author names, vote counts, quiet verse) -> next. Lobby first, finale last. Host has Next/skip/remove-answer buttons.
- <3 answers: skip voting, go straight to reveal.
- Round 8 is the fun one: no verse.
- Announcer: edge-tts clips (en-US-GuyNeural) generated by `scripts/make-announcer.py` into `public/gameshow/`; host plays them (needs one click to unlock audio).
- Home button shows only on 2026-10-25 (or `?gs=1` for preview). Teacher home gets a "Start Game Show" link.

## Calls made (Dillon can override)
Voting kept; vote question varies per round; 140-char answer cap; names shown only at reveal; no points.
